# 车辆加油账本

把 Excel《车辆信息》里的加油记录做成手机网页：每次加油记一笔，油耗、油价、总花费自动算。

- 大字号、大按钮，适合长辈使用
- 表格 / 大卡片两种看法，点一行就能改
- 数据保存在手机浏览器本地，打开即可记录
- 可「添加到主屏幕」，像 App 一样使用，没网也能看
- 导出真正的 Excel（`.xlsx`，带公式）、`.json` 备份、`.csv`
- 可选云同步：用 GitHub 私有 Gist 存数据，多台手机输入同一个「同步码」即可看到同一份

## 打开地址

https://allenkanyunlei.github.io/car-log/

## 计算方法（与 Excel 一致）

| 项目 | 公式 |
| --- | --- |
| 油耗 | 加油量 ÷ 里程 × 100（升/百公里） |
| 单价 | 费用 ÷ 加油量（元/升） |
| 合计 | 里程、油量、费用分别求和；平均油耗 = 总油量 ÷ 总里程 × 100 |

## 云同步怎么用

1. 打开 https://github.com/settings/tokens/new?scopes=gist&description=car-log
2. 只勾选 `gist`，点「Generate token」，复制 `ghp_` 开头的字符
3. 网页里「说明 · 备份」→「云同步」→ 粘贴 → 开启同步
4. 另一台手机粘贴同一个同步码即可

同步码等于钥匙，只给自己的家人；关闭同步不会删除已有记录。

## 文件

- `index.html` — 页面结构
- `styles.css` — 样式（大字号、公路主题）
- `app.js` — 计算、记录、保存、备份、云同步
- `xlsx.js` — 生成 `.xlsx`（纯前端，无依赖）
- `records.js` — 初始的 26 条记录（来自 Excel）
- `sw.js` / `manifest.webmanifest` — 离线与「添加到主屏幕」

## 注意

默认记录只存在当前手机的这个网页里，不会上传服务器。换手机或清理 Safari 数据会丢失，请定期导出备份；开启云同步后数据同时保存在你的私有 Gist 里。
