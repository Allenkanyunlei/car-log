    说明与备份

    数据存在哪里

    记录默认只保存在这台手机的这个网页里，不会上传服务器。换手机、清理浏览器数据都会丢失，所以请定期导出备份；打开下面的「云同步」后，数据会存到你自己的 GitHub 私有 Gist，多台手机就能看同一份。

    还没有导出过备份

    云同步（多台手机看同一份）

    开启后，每次保存都会自动同步到你自己的 GitHub 私有 Gist；家里其他手机粘贴同一个同步码，就能看到一样的记录。

    还没有同步码？点这里生成：登录 GitHub → 只勾选 gist → 点页面最下面的「Generate token」→ 复制那串 ghp_ 开头的字符粘贴到上面。只给 gist 权限，不要勾别的。

    已开启

    其他手机：打开同一个网址 →「说明 · 备份」→ 粘贴这个同步码 → 开启同步，记录会自动出现。同步码等于钥匙，只发给自己家人。

    放到苹果手机桌面上

    1. 用 Safari 打开这个网页。
    2. 点屏幕底部中间的「分享」按钮（方框带向上箭头）。
    3. 往下滑，点「添加到主屏幕」，再点「添加」。
    4. 以后从桌面图标打开，就像一个小软件，没网也能看。

    怎么填

    1. 加满油后，点「记一笔加油」。
    2. 填日期、这次跑的公里数、加了多少升、花了多少钱。
    3. 点保存，油耗和油价会自动算好。
    4. 填错了，点记录右上角的「修改」。

    计算方法

    油耗 = 加油量 ÷ 里程 × 100（升/百公里）
    油价 = 费用 ÷ 加油量（元/升）
